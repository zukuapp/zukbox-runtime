## 한국어

밝은 배경에는 `zuku-logo-light.png`, 어두운 배경에는
`zuku-logo-dark.png`를 사용합니다. 이미지의 종횡비와 투명도를 유지하고,
로고를 다시 그리거나 색상·글자·슬로건을 이미지에 합성하지 않습니다.

공식 슬로건은 모든 언어에서 아래 문구를 그대로 사용합니다.

> ZUKU - 내가 불러 일으키는 새로운 창작.

로고는 `<picture>`로 테마별 이미지를 고르고 `alt="ZUKU"`를 지정합니다.
본문과 링크는 검색 및 접근성을 위해 텍스트로 유지합니다.

## English

Use `zuku-logo-light.png` on light backgrounds and `zuku-logo-dark.png`
on dark backgrounds. Preserve their aspect ratio and transparency.
Do not redraw, recolor, or composite new lettering or slogans into the logo.

Use the exact official slogan above in every locale; do not translate it.
Use `<picture>` to select the theme logo and set `alt="ZUKU"`.
Keep body content and links as text for search and accessibility.
